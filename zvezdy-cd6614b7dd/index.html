2

Установи приложение ChatGPT

Codex живёт внутри приложения ChatGPT для компьютера. Выбери свою систему.

Mac M1 и новее

  1. Открой learn.chatgpt.com/docs/app
  2. Нажми «Download for macOS (Apple Silicon)»
  3. Открой скачанный файл и перетащи ChatGPT в «Программы»
learn.chatgpt.com/docs/app

Какой у тебя Mac: меню Apple → «Об этом Mac». Нужна строка «Чип Apple M…».

Windows 10 и 11

  1. Открой Microsoft Store и найди ChatGPT от OpenAI
  2. Нажми «Получить» и дождись установки
apps.microsoft.com

Или одной командой в PowerShell:

winget install --id 9PLM9XGG6VKS -s msstore

Возьми запись урока из папки «Входящие». Найди 5 моментов для рилзов по 30–40 секунд, сделай субтитры. Сначала покажи список моментов.

Добавляй «сначала покажи»: так ты правишь план, а не готовую работу.
